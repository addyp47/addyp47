# Apartment Planner

A client-only web app for planning an apartment's layout and decor.
Built with React, TypeScript, Vite, and SVG. There is no backend, and everything stays in your browser.

```bash
cd apartment-planner
npm install
npm run dev        # http://localhost:5173
npm test           # geometry + analysis unit tests
npm run build      # static build in dist/
```

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the data model, component structure,
why the plan uses SVG, and how a 3D view and RoomPlan import will fit in later.
